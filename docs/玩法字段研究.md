# 玩法字段映射依据

本次研究只读取已安装游戏资源和存档，没有修改游戏文件或玩家存档。映射保存在 `backend/gameplay_catalog.json`，适用于其记录的 `ArkPark2-Windows.utoc` SHA-256 对应版本；升级游戏后需要重新核对。

## 背包物资

存档 `S_背包物资` 每条记录含有 `表格索引` 和 `数量`。物品名称来自游戏的 `/Game/ArkPark/Blueprints/武器/背包物品/数据/T_物品信息`，共 132 行，不能将数组位置直接当作物品编号。

例如：索引 `2` 为木材，`28` 为鲜橙，`39` 为辣椒，`49` 为黑胡椒，`86` 为大蒜。相同物品可以出现在多个背包位置，每个位置的数量独立保存。

## 发射器附加技能

附加技能保存在每把发射器的 `携带的核心` 枚举数组。中文名来自 `/Game/ArkPark/Blueprints/武器/发射器/BPs/E_发射器元素核心` 的 `DisplayNameMap`，包含七种元素的三级技能，共 21 项。

当前样本发射器 0 的核心数组为空；发射器 1 的数组为：

| 存档枚举 | 游戏名称 |
| --- | --- |
| `E_发射器元素核心::NewEnumerator10` | 雷电2 |
| `E_发射器元素核心::NewEnumerator17` | 风暴3 |
| `E_发射器元素核心::NewEnumerator2` | 雷电1 |

枚举名称末尾的数字不一定等于序列值。例如 `NewEnumerator7` 是火焰3，其实际序列值为 14；写入时必须使用完整、已核实的枚举名称。

## 剧情任务

v0.4.0 新增实验性剧情索引调整：展示 0–69 全部 70 条记录，可搜索标题、目标与详情；仅 1–67 完整任务可选。选择后需统一预览保存，修改前自动备份；不会同步奖励、NPC、地图或任务前置状态，实际游戏跳转待验证。

存档顶层 `剧情任务索引` 保存主线阶段。任务名、目标和详情来自 `/Game/ArkPark/Modes/PCs/故事模式/PC_方舟乐园` 的 `剧情任务名字和检查间隔` 函数，按其 `EX_SwitchValue` 分支恢复映射。

索引 0 至 68 有三项对应表；其中部分原始文字为空。索引 69 只有详情分支，因此不能将其视为完整任务或认定所有剧情已经完成。未知阶段应显示索引和无法映射的原因。

当前样本索引 54 对应“AAA级拉面大王”，目标为“将 拉面龙 的舒适度 提高至 2500”。这是游戏任务原文，不代表修改器能够可靠计算当前舒适度。剧情的完成检测包含运行时条件；存档索引和静态任务文本不能替代未持久保存的实时目标计数。

## 游戏统计

当前主存档可直接读取的命名统计包括：制作美食数量、拉面龙总营业额度、完成派送外卖单数、派送次数、拾取次数、捞桶次数，以及世界岛日期和星期。统计含义沿用游戏字段名；名称相似的两个字段不合并。

`拉面龙开业时长` 的底层类型是 `DateTime`，尽管字段名包含“时长”，不能直接将其 ticks 显示为游玩时长。`拉面龙等级` 是向量结构，各分量的具体业务含义需要单独核实。

## 右键瞄准倍率的存档限制

已核实的 `S_发射器数据` 结构只有 ID、等级、增益、配件、皮肤和核心六项，不包含独立瞄准倍率。现有存档保存配件名称，瞄准视野设置由游戏资源表决定。

例如 SVD英雄的机瞄设置引用 `T_Ironsights_MP9/默认`，再引用 `/Game/InfimaGames/LowPolyShooterPack/Data/Weapons/Settings/DT_LPSP_WEP_Settings_Ironsights/默认`。该资源含 `MultiplierFieldOfView` 等参数，属于游戏资源，而不是可直接写入存档的字段。SVD 的瞄具资源表只有“默认”和“全息瞄准镜”。因此任意瞄准倍率目前需要资源模组或运行时方案，不能通过在修改器数据库里保存一个倍率实现。

## 本地研究证据

工作目录中的 `build/research/gameplay-*.json` 为 CUE4Parse 导出结果，未加入发布包。用于映射的主要文件是 `gameplay-items-0.json`、`gameplay-core-0.json` 和 `gameplay-quest-169.json`。瞄准限制另参考 `gameplay-weaponstruct-0.json`、`gameplay-svd-3.json`、`gameplay-svd-ironsight-0.json` 和 `gameplay-zoom-table-0.json`。

这些是静态资源与存档证据；新增技能写入后的实际效果仍需进游戏验证。

## 本版编辑范围与状态（2026-10-15）

v0.4.0 移除每把发射器 3 项编辑限制，保留顺序和重复项；超过三项的已知列表仍可编辑。游戏内加载与效果上限未实测。未知枚举、不同结构或资源指纹不符时，技能列表只读保留。增加、替换和清空均经过嵌套数组长度重建、重新解析、自动恢复点及同一事务写入。

用户已确认火力、备弹、射速、移速和背包指定位置数量修改通过游戏测试；等级、稳定及新增技能效果未作同等确认。火力等字段是发射器“增益”结构数值，不称作游戏资源中的最终基础属性。

舒适度工具未通过可靠性测试，前端卡片和高级参数中的舒适度字段均已隐藏。剧情目标仍显示游戏原文。瞄准倍率功能经用户确认暂缓，产品只显示当前存档不支持的说明，不修改游戏资源。
