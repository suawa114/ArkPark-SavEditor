## 修改器显示规则（v0.3.0）

- 主进度和家园文件均存在、类型与关键结构可解析时，显示“已有存档”。
- 没有正常主进度、家园或相关搬迁记录时，显示“无存档”。
- 只有部分文件、只有搬迁记录、文件损坏或只有关联的双点异常家园名时，显示“缺少文件”，列出具体缺失文件及原因；若主进度仍能读取则展示摘要，但暂不开放编辑。额外异常文件不替代正常家园，也不影响已完整的正常配对。
- 搬迁记录是可选附属文件，不把没有 A/B 搬迁记录的新槽位判为损坏；全局设置也不计入某槽位的必需文件。
- v0.5.3 修正：剧情索引、世界岛日期及统计字段不作为必需字段。主进度仍以可读取的货币和剧情、武器或背包结构之一确认身份，家园仍须有可解析的建造结构；缺少剧情时显示“未记录”，不开放剧情修改，不影响其他可靠字段的编辑。没有将缺失字段当作 0 或自动补写。
- 用户指定的“存档天数”是游戏累计天数。目前未找到独立字段，显示“未单独记录”；世界岛日期按原值显示，不能由现实文件时间或开业时间推算累计天数。
