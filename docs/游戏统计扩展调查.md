## 暂不作为含义已确认的统计

- `拉面龙等级` 是 Vector：第一槽 `(4, 526, 3800)`，第二槽 `(4, 2245, 3800)`。仍需核实各分量，不能只凭名称标为等级、经验及升级需求。
- `拉面龙开业时长` 是 DateTime，不是持续时长；尚未核实时区及更新时间语义，不显示累计游玩时间。
- `S_称号/所有称号` 分别为 145、146 条。文本及颜色可以用于研究，但不能仅按条目数认定已获得称号或已完成成就数，需要核实获得/注册逻辑。
- `S_可修缮的建筑物` 可读到已完成组件和已提供材料；第二槽的组件数组含空路径，不可直接用数组长度当作完成量或修缮百分比。
- 店员等级、属性、经验、薪资以及动物、菜谱名称可作为展开详情。薪资字段的结算周期未核实，不宜直接标为每日工资支出。
- 当前两个主存档没有找到独立命名的击杀总数、死亡次数、射击次数、命中率、累计游玩时长等字段。这里只能说明本次存档未发现，不能断言游戏运行时没有记录。
- 舒适度与通缉值延续原研究限制，不作为本轮新增统计。
